# SING & PLAY

لعبة غناء جماعية أونلاين — PWA بواجهة عربية RTL.

## التقنية
- الواجهة: Vite + React + TypeScript + vite-plugin-pwa
- الخلفية: Supabase (Postgres + Auth + Realtime + Storage)
- الاستضافة المجانية: Cloudflare Pages (أو Netlify/Vercel)

## التشغيل
```
npm install
cp .env.example .env.local   # ثم املأ مفاتيح Supabase
npm run dev
```

## تراكات الطبلة
ضع ملفات `shaabi.mp3` و`oriental.mp3` و`fast.mp3` داخل `public/beats/` (تفاصيل في README.txt هناك).

## البنية
- `src/game/` قواعد اللعبة والأنواع (مصدر واحد للقيم)
- `src/lib/` الاتصال بالخدمات
- `src/features/<ميزة>/` كل ميزة في مجلدها (auth, rooms, lobby, play, voting, profile, admin)
- `src/styles/` ألوان وخطوط الهوية المعتمدة
- `supabase/migrations/` ملفات قاعدة البيانات (تبدأ في المرحلة 2)

## منصة الألعاب المتعددة

SING & PLAY دلوقتي منصة فيها أكتر من لعبة. اللاعب بيسجّل دخول وتظهر له **كروت الألعاب في الصفحة الرئيسية** (زر «i» لشرح اللعبة)، ولما يدوس على لعبة تفتح صفحتها: غرفة سريعة، إنشاء غرفة، والغرف المفتوحة للعبة دي (الغرفة بتتعمل للعبة معيّنة). الأدمن بيبدأ اللعبة وكل الأجهزة بتنتقل ليها. جوه لعبة أنا مين فيه زر «مغادرة الغرفة» لكل اللاعبين.

| اللعبة | المعرّف | مكانها |
|---|---|---|
| يلا غني مع الحرف | `sing` | `src/features/play/*` (زي ما هي بدون تغيير) |
| أنا مين؟ | `who_am_i` | `src/games/who-am-i/*` (واجهة) + `supabase/functions/who-am-i/*` (خادم) |

**المشترك بين الألعاب:** الحسابات والغرف واللاعبين وصلاحية الأدمن فقط. كل لعبة محرّكها وشاشاتها وقواعدها ونقاطها لوحدها.

### إزاي تضيف لعبة جديدة
1. سطر في جدول `games` (قاعدة البيانات): المعرّف والاسم وأقل/أكتر عدد لاعبين.
2. مجلد للّعبة في `src/games/<اسم>/` وطريقة تشغيلها في `LobbyScreen` (زي `WhoAmIGame`).
3. لو اللعبة فيها أسرار أو نقاط: Edge Function خاصة بيها على Supabase، والنقاط العامة بتتسجّل بـ`award_game_points` (بتمنع التكرار).
4. شكل الكارت: اسمها وشرحها في `src/features/games/gameUi.ts`، ورسمتها (SVG) في `GameArt.tsx`.

### النقاط
كل لعبة بتحسب نقاطها لوحدها. نقاط «أنا مين؟» بتتضاف لـ`profiles.total_points` من الخادم عن طريق `game_point_awards` (قيد فريد = مفيش احتساب مرتين).

### الاختبار

### النشر
- قاعدة البيانات: شغّل `0014_games_platform.sql` ثم `0015_game_first.sql` من `supabase/migrations/` في SQL Editor (مرة واحدة لكل ملف، بالترتيب).
- الخادم: `supabase/functions/who-am-i/index.ts` (ملف واحد مولَّد) ينتشر على Supabase باسم `who-am-i`، مع **إيقاف** «Verify JWT with legacy secret» (الدالة بتتأكد من هوية اللاعب بنفسها). لو عدّلت أي ملف في المجلد شغّل `node scripts/build-edge-function.mjs` وانشر `index.ts` من جديد.
- الواجهة: على Cloudflare بنفس طريقتك المعتادة.

### تحديثات اللعب (آخر تعديل)
- **تغيير اللعبة جوه الغرفة:** الأدمن في شاشة الانتظار يدوس «غيّر اللعبة» ويختار لعبة تانية، والكل بيشوف التغيير لحظياً (من غير غرفة جديدة). الألعاب اللي أقصى عدد لاعبينها أقل من عدد اللي في الغرفة بتتقفل.
- **أنا مين؟:** بعد ما تدوس «أنا عرفت!» مفيش رجوع للأسئلة، لازم تختار (متأمّن في الخادم كمان: الرجوع وإرسال سؤال أثناء التخمين مرفوضين).
- **أتوبيس كومبليت:** (١) شات جوه اللعبة (زر في الشريط اللي فوق، وبيشتغل لو الشات مفعّل في إعدادات الغرفة). (٢) الأدمن صح/غلط بس: أمر `editAnswer` اتشال من الخادم والواجهة. (٣) شاشة واحدة: اختار النقاط (وكارت ×٢ لو عايز) واكتب الإجابة وأرسل في ضغطة واحدة، والمقدمة اللي كانت بتاخد وقت من السؤال اتشالت، ونتيجة السؤال بقت ٨ ثواني بدل ١٢.
- بعد تعديل الخادم: انشر من جديد `supabase/functions/who-am-i/index.ts` و`supabase/functions/bus-complete/index.ts` (الاتنين اتولّدوا من جديد). مفيش migration جديدة.
